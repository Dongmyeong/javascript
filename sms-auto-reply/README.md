# 문자 자동응답 (SMS Auto Reply)

특정 상대와의 **문자(SMS) 대화를 규칙대로 자동 진행**하는 개인용 Android 앱입니다.
갤럭시 Z 폴드7(Android 16, One UI 8)에 직접 설치해서 쓰는 것을 기준으로 만들었습니다.

- **시나리오** = 상대 한 명 + 시작 방식 + 단계들
  - 시작 방식: 예약 시각에 내가 먼저 보내기(한 번 / 매일 / 매주 요일) 또는 상대 문자를 받으면 시작
  - 단계: 보낼 문구 + "답장에 이런 단어가 있으면 다음 단계로" 규칙 + 답장 없을 때의 처리
- 답장에 포함된 단어로 분기해서 대화처럼 이어짐 (AI 없음, 전부 내가 정한 규칙)
- 문구에 `{이름}`, `{시각}`, `{날짜}` 치환
- 특정 시간대에만 반응, 대화 끝난 뒤 재시작 대기(쿨다운), 대화 만료, 최대 발송 수 등 안전장치
- 앱을 켜두지 않아도 동작 (매니페스트 등록 리시버 + AlarmManager, 재부팅 후 자동 복구)
- 듀얼 SIM이면 문자를 받은 SIM으로 답장, 최근 기록 화면

SMS 전용입니다. RCS(채팅+), 카카오톡 등 다른 메신저는 대상이 아닙니다.

## 예시 시나리오

"매일 19:00에 엄마에게 저녁 안부 묻기"

| 단계 | 보낼 문구 | 답장 규칙 |
|---|---|---|
| 1 (시작) | `{이름}, 저녁 먹었어?` | `먹었, 응` → 2단계 / `아니, 안` → 3단계 / 60분 답장 없으면 → 4단계 |
| 2 | `잘했어! 푹 쉬어.` | (규칙 없음 → 대화 종료) |
| 3 | `얼른 챙겨 먹어~` | (규칙 없음 → 대화 종료) |
| 4 | `답이 없네, 바쁜가 보다.` | (규칙 없음 → 대화 종료) |

"상대가 문자하면 키워드로 답하기" 는 시작 단계의 문구를 비워 두고(보내지 않고 기다림) 규칙만 넣으면 됩니다.
`*` 는 어떤 답장이든 해당되는 단어라서 마지막 규칙에 기본 응답으로 쓰기 좋습니다.

## 설치 방법 A: PC 없이 GitHub에서 APK 내려받기 (권장)

`sms-auto-reply/` 아래 파일이 바뀌어 푸시되면 GitHub Actions가 자동으로 APK를 빌드해서
저장소 **Releases** 의 `sms-auto-reply-latest` 프리릴리스에 올려 둡니다.

1. 폰 브라우저로 이 저장소의 **Releases** 페이지를 열고 `SmsAutoReply-latest.apk` 를 내려받습니다.
2. 다운로드한 파일을 탭해 설치합니다. 처음 한 번은 **설정 → 보안 → 출처를 알 수 없는 앱 설치**에서
   사용 중인 브라우저(또는 내 파일 앱)에 설치 권한을 허용해야 합니다.
3. 이후 코드가 바뀌면 같은 위치에서 새 APK를 내려받아 덮어 설치하면 됩니다.
   서명 키를 저장소에 고정해 두었기 때문에(`keystore/debug.keystore`) 삭제 없이 업데이트 설치가 됩니다.

빌드 상태는 저장소 **Actions** 탭의 "SMS Auto Reply APK" 워크플로에서 볼 수 있고,
**Run workflow** 버튼으로 수동 빌드도 가능합니다.

> 저장소에 들어 있는 디버그 키스토어는 개인용 사이드로드 편의를 위한 것입니다.
> 같은 키로 서명된 APK는 누구나 만들 수 있으므로, 앱을 배포할 일이 생기면 별도의 릴리스 키를
> GitHub Secrets로 관리하는 방식으로 바꿔야 합니다.

## 설치 방법 B: Android Studio에서 직접 빌드

1. [Android Studio](https://developer.android.com/studio) 최신 버전 설치
2. Android Studio에서 **Open** → 이 `sms-auto-reply` 폴더 선택 → Gradle 동기화가 끝날 때까지 대기
   (SDK Platform 36이 없다고 하면 안내에 따라 설치)
3. 폴드7에서 **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7회 탭**으로 개발자 옵션을 켜고,
   **개발자 옵션 → USB 디버깅** 활성화
4. USB로 연결하고 Android Studio 상단에서 기기 선택 후 **Run ▶**

USB 없이 설치하려면 **Build → Generate Signed App Bundle / APK → APK**로 서명된 APK를 만들어
폰으로 옮긴 뒤 설치하세요. 개인용이라 Play 스토어 배포는 고려하지 않았습니다.
(Play 스토어는 SMS 권한을 쓰는 앱을 기본 문자 앱 등으로 제한합니다.)

## 처음 실행 시 설정

1. **권한 허용** 카드에서 SMS 수신/전송 권한 허용
   - 권한 창이 뜨지 않거나 바로 거부된다면 Android 15+의 **제한된 설정** 때문입니다(브라우저로 내려받아 설치한 앱에 적용).
     **설정 → 애플리케이션 → 문자 자동응답 → 오른쪽 위 ⋮ → 제한된 설정 허용** 을 누른 뒤 **권한 → SMS → 허용**으로 바꾸세요.
2. **정확한 시각 알람** 카드에서 '알람 및 리마인더' 허용 (예약 문자가 정시에 나가도록)
3. **배터리 최적화 예외** 카드에서 이 앱을 예외로 등록
   - 추가로 **설정 → 배터리 → 백그라운드 사용 제한 → 절전 예외 앱**에 이 앱을 넣어두면 더 안전합니다.
4. 오른쪽 아래 **시나리오 추가** → 상대, 시작 방식, 단계 입력 후 저장
5. 상단 **자동응답** 스위치를 켬. 예약 시나리오는 카드의 **지금 바로 시작**으로 미리 테스트할 수 있습니다.

## 동작 방식

```
예약 시각 도달 (AlarmManager → AlarmReceiver)      문자 수신 (SMS_RECEIVED → SmsReceiver)
        │                                                  │
        └──────────────► ConversationEngine ◄──────────────┘
                          (순수 상태 기계)
                 - 시나리오/대화 상태를 보고 다음 단계 결정
                 - 보낼 문자, 예약할 타임아웃 등을 Action 목록으로 반환
                                  │
                          ActionExecutor
                 - SmsSender 로 문자 전송 (80자 초과 시 분할)
                 - AlarmScheduler 로 답장 대기 타임아웃 알람 등록/해제
```

안전장치: 마스터 스위치, 시나리오별 스위치, 내 문구가 그대로 되돌아오면 무시(루프 방지),
대화당 최대 발송 수, 무응답 만료, 대화 종료 후 쿨다운, 등록되지 않은 번호는 기록조차 남기지 않음.

## 프로젝트 구조

```
app/src/main/java/com/dongmyeong/smsautoreply/
├── MainActivity.kt / AppController.kt   화면 전환, UI가 호출하는 동작 모음
├── SmsReceiver.kt                      문자 수신 → 엔진 → 실행
├── SmsSender.kt                        SmsManager 래퍼 (듀얼 SIM, 분할 전송)
├── PhoneNumbers.kt                     한국 번호 정규화/비교
├── data/Models.kt                      Scenario, Node, Transition, Conversation, AppState
├── data/SettingsRepository.kt          DataStore(JSON) 저장소
├── engine/ConversationEngine.kt        순수 판단 로직 (단위 테스트 대상)
├── engine/Schedule.kt, Templates.kt    다음 발송 시각 계산, {이름} 치환
├── scheduling/AlarmScheduler.kt        AlarmManager 래퍼
├── scheduling/AlarmReceiver.kt         예약 발송 / 답장 대기 시간 초과 처리
├── scheduling/BootReceiver.kt          재부팅·업데이트 후 알람 복구
└── ui/                                 HomeScreen, ScenarioEditorScreen, NodeEditorScreen
```

## 테스트

```
./gradlew :app:testDebugUnitTest
```

`ConversationEngine`(분기, 타임아웃, 쿨다운, 루프 방지 등), `Schedule`(다음 발송 시각), `PhoneNumbers`(번호 정규화)에 대한 단위 테스트가 들어 있습니다.

## 알아둘 점

- 문자 앱에 알림이 뜨는 것과 별개로, 이 앱은 문자를 가로채거나 숨기지 않습니다.
- 발신자가 전화번호가 아닌 문자(은행, 인증번호 등 알파벳 발신자)는 무조건 무시합니다.
- 규칙은 위에서부터 순서대로 검사하므로, "안 먹었어"처럼 다른 규칙의 단어("먹었")를 포함하는 답장은 부정 표현 규칙을 먼저 두어야 합니다.
- 쿨다운을 0으로 두면 상대의 모든 문자에 매번 새 대화가 시작됩니다. 상대도 자동응답이면 요금이 늘 수 있으니 주의하세요.
